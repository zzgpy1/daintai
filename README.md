# 🌍 国内电台 - GlobalRadio

基于 Vue 3 的跨平台网络电台播放器，支持 Web、Windows 桌面端（Electron）和 Android 移动端。
数据来源于 Radio Browser API，专注于国内电台（自动过滤为 CN 国家码）。

## ✨ 主要功能

- 📻 国内电台列表（默认加载国内频道）
- 🔍 搜索电台（按名称、标签、省份）
-🏷️ 分类筛选（音乐、新闻、谈话、体育等）
- 🗺️ 省份分类（覆盖地级市及县级频道）
- ❤️ 收藏电台
- 🕒 播放历史记录
- 🌙 深色/浅色主题切换
- 🌐 多语言支持（中文/英文）
- 🔊 音量调节与静音
- ⏰ 睡眠定时器
- 🔄 随机发现电台
- 📱 响应式设计（适配手机和桌面）

## 🚀 快速开始

### 开发模式
```bash
# 安装依赖
npm install

# 启动 Web 开发服务器
npm run dev

# 构建 Web 版本（输出到 dist/）
npm run build

# 预览构建后的 Web 版本
npm run preview
```
